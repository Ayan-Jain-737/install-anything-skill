How It Works

A universal pipeline designed to turn arbitrary repositories into production-grade agent skills without manual wrapper authoring.

01 / Detection

README-First Intelligence

Scans repository documentation and manifests to detect preferred installation methods (Cargo, Go, Pip, NPM) and intended CLI flags before running.

02 / Build

Native Compilation

Automatically builds binaries for Rust, Go, Python, and Node projects in isolated workspaces, avoiding global pollution.

03 / Scoping

Active-Agent Isolation

Detects your caller runtime (Claude, Cursor, Codex, Gemini, Hermes) and targets its specific skills folder. Never touches inactive harnesses.

04 / Exposure

PATH Symlinking

Symlinks built executables directly into ~/.local/bin so newly installed tools are immediately available in shell sessions.

Active-Agent Directory Scoping

Guarantees zero ghost folder pollution. Installations are strictly scoped to the active caller.

Claude Code

~/.claude/skills/ias & /ias

Auto-detected during Claude Code runtime. Installs skill wrappers and slash command definitions.

Open Agents

~/.agents/skills/ & .skill-lock.json

Canonical global store compatible with npx skills across multi-agent pipelines.

Cursor & Codex

~/.cursor/skills/ & ~/.codex/skills/

Targeted on demand with --agent cursor or --agent codex with zero ghost folders.

Hermes & OpenCode

~/.hermes/ & ~/.config/opencode/

Direct execution support for command runners and local development assistants.

Gemini & Antigravity

~/.gemini/skills/ias

Detects ANTIGRAVITY_AGENT and links binaries without contaminating other agent directories.

Custom & Headless

~/.local/bin/ias

Compiles Rust, Go, Python, and Node binaries and exposes symlinks for any terminal agent.
